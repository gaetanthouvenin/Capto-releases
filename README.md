# Capto releases

Releases of [Capto](https://github.com/gaetanthouvenin/Capto), a screen-capture tool for Windows. This repository holds the installers, the update packages and the release notes, not the source code.

- **Install:** download `Capto-win-Setup.exe` from the [latest release](https://github.com/gaetanthouvenin/Capto-releases/releases/latest) and run it. Capto installs for the current user only, under `%LocalAppData%\CaptoApp`. `Capto-win-Portable.zip` is the same application without installation.
- **Updates:** installed copies check this repository's releases and offer new versions from the notification-area icon.
- The installer is not signed yet: Windows SmartScreen warns about an "unknown publisher". Click **More info**, then **Run anyway**.

Releases are published automatically by the release workflow of the source repository; please do not push to this repository by hand.
